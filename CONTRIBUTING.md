# Contribution

Merci de votre intérêt pour ASM Paris Navigator.

1. Ouvrez d’abord une issue pour décrire le changement proposé.
2. Travaillez dans une branche dédiée.
3. Exécutez `npm run check` avant toute pull request.
4. N’ajoutez jamais de clé API, mot de passe, jeton ou donnée privée au dépôt.
5. Respectez l’identité visuelle et les fonctions existantes de l’application.

L’acceptation d’une contribution ne transfère aucun droit sur la marque ASM Technologies.
