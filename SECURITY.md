# Politique de sécurité

## Versions prises en charge

La dernière version publiée est la version prise en charge.

## Signaler une vulnérabilité

Ne publiez pas publiquement les détails d’une vulnérabilité exploitable dans une issue.
Utilisez de préférence la fonction **Private vulnerability reporting** de GitHub si elle est activée sur le dépôt.

Indiquez : la version concernée, les étapes de reproduction, l’impact observé et toute proposition de correction utile.
